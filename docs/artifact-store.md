# 产物持久化与清理

> 原则：**花钱生成的、或用户亲手写的东西，不能只存在一台设备的浏览器里**；每份产物要能回答三个问题——存在哪、什么时候算过时、过时了怎么处理。允许不兼容旧作品（旧格式由「清理」收走，不做迁移）。

## 1. 现状与判断

| 产物 | 现在存在哪 | 判断 | 处理 |
|---|---|---|---|
| 章节总结 + 关联 + 全书综述 | WebDAV `{名}-完整摘要.md`（头部 HTML 注释元数据）；本机 IndexedDB 章节缓存（键含文件指纹 / 内容 / 模型 / prompt / 语言） | 合理。缓存键已包含全部输入，换模型 / prompt 自动失效 | 保持；MD 仍是人可读的导出 |
| 关键图表 | WebDAV `{名}-完整摘要.json` | 合理 | 保持 |
| v3 章节旁路（别名等） | WebDAV `{名}-完整摘要.meta.json` | 合理 | 保持 |
| 速读 / 自测题 | **仅本机 IndexedDB**（`juhua-study`，键 = 书名 + 各章总结长度的指纹） | ❌ 现在是**自动花钱生成**的，换设备 / 清浏览器就丢，要重新付费 | 见 §2：进 WebDAV 信封，本机作缓存 |
| 自测答题记录 | 同上 | ❌ 用户数据 | 同上，按题目 id 合并（取最早一次作答） |
| 笔记（划线 / 批注） | **仅本机 IndexedDB**（`juhua-notes`） | ❌ **最不该丢的**：用户亲手写的 | 见 §2：必须同步，条目级合并 + 墓碑 |
| 问书对话 | 内存 | ✅ 有意不持久（一次性问答，答案依据可再现） | 保持 |
| 书库索引 / 封面 | WebDAV `.juhua/library.json.gz`；KV 云端书目 | ✅ 已按「云端为主数据」重做并审查过 | 保持（见 covers-kv.md） |
| 处理历史 / 用量 | 共享状态 KV（追加型分区） | ✅ | 保持 |

## 2. 统一信封（下一步，未实现）

速读 / 自测 / 笔记各存一个文件：`{syncPath}/.juhua/books/<bookKey>/<kind>.json.gz`，内容是同一种信封：

```jsonc
{
  "schema": 2,                 // 不兼容升级就加一；读到更高版本的文件只读不写
  "kind": "study" | "quiz" | "notes",
  "bookKey": "…",              // 书的内容指纹（studyKeyOf / notesKey）
  "inputsFp": "…",             // 上游输入指纹：速读 / 自测 = 各章总结的指纹；笔记 = 空（用户数据，没有上游）
  "model": "…", "promptVersion": "…",   // 仅 AI 产物
  "createdAt": 0, "updatedAt": 0,
  "data": { }
}
```

- **过时判定**只有一个：`inputsFp` ≠ 当前上游指纹。过时的产物**不自动删**，在清理里单列「已过时」，由用户决定。
- **读**：本机有且 `updatedAt` 不旧 → 直接用；否则读 WebDAV；**写**：生成 / 修改后异步写回（失败静默，下次再试）。
- **笔记合并**：条目级 `id + updatedAt`，删除用墓碑（`deleted: true`，保留 30 天），两端取较新者；这与书库索引 `mergeIndex` 同一思路。
- 读不懂的信封（schema 更高 / 结构坏）：当作不存在，不覆盖、不报错。

## 3. 过时产物的清理（已实现）

入口：设置 → 书库 →「清理过时产物」（`ArtifactCleanup` + `artifactCleanup*.ts`）。

| 类别 | 判定 | 默认 |
|---|---|---|
| 旧版格式 | `{名}_chapter_N_summary.md`、`_chapter_N_mindmap.json`、`_combined_mindmap.json`：早已被「完整摘要」取代 | 勾选 |
| 悬空附件 | `-完整摘要.json` / `.meta.json` 的主 MD 已不存在，单独读不出来 | 勾选 |
| 书已不在 | 主 MD 在，但对应的书既不在 WebDAV、也不在云端书目（它的附件一并列出，保持成套） | **不勾选**：摘要仍可读，是否保留由用户定 |

安全闸（沿用云端书架审查的结论）：

1. 打开即**强制重扫**，扫描失败 / 同步目录里一本书都没扫到（多半目录配错）→ 拒绝给清单，什么都不删；
2. 「书还在」= WebDAV 真书 **∪** 云端书目里的记录，任一有就不算「书已不在」；
3. 只看同步目录之下、且命名严格匹配的产物文件；`.juhua` 下的任何东西、书籍文件、其它命名的文件**永不进入清单**；
4. 删除前二次确认；并发 3，单个失败不影响其余，结果逐项回报。

## 4. 下一步

2. `.juhua/books/` 下「书已不在」的整包清理；
3. 笔记的 `{名}-笔记.json` 导出继续保留为人可读副本（与 tasks.md 7.1 对齐）。
