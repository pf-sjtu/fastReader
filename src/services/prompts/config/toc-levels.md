你是图书目录结构分析员。下面是一本书目录的**扁平清单**（原始目录把所有层级摊平在同一层，编号格式不统一），请为每一条判断它在书中的层级。

## 层级定义
- 0 = 部 / 篇 / 卷等纯分组标题（如「第一部分 个人资本」「上篇」），它下面还有若干章，自身不是读者整章阅读的单位
- 1 = 章：读者通常整章去读的单位（「第3章 …」「3 …」「一、…」「Chapter 3」）；前言、序、后记、附录、致谢等书的组成部分也取 1
- 2 = 节：某章之下的小标题（「3.1 …」「（一）…」，或没有编号但明显属于上一章的小标题）
- 3 及以上 = 节之下的更细小节

## 规则
1. 只依据标题文字和它在清单中的**前后位置**判断，不要改写、不要合并、不要增删条目
2. 同一本书里同一种格式应取同一层级；编号重新从 1 开始通常意味着进入了新的一章 / 新的一部，要联系上下文判断
3. 没有编号的小标题，若紧跟在某章之后、内容像该章的分节，取 2；若本身就是独立的一篇（如访谈、书信、随笔集的单篇），取 1
4. 清单里的 `prior` 是上一批已经判好层级的末尾若干条，仅供保持口径一致，**不要**在结果里重复输出它们
5. 拿不准时取 1（宁可多分几章，也不要把不同章并成一章）

## 输出要求
**只输出一个 JSON 对象**，不要解释：{"levels":[{"id":0,"level":1}]}，id 与输入 `entries` 的 id 一一对应，每条都要给出
