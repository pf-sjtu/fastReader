# UI 验收演示页（真实浏览器）

jsdom 看不出布局、悬浮定位和滚动。这页把三处容易回退的界面放在一起，用与主应用同一套插件 / 别名构建，在真实浏览器里核对：

- 状态栏：平等的三阶段切换「书库 · 设置 · 处理」（演示页并排放三条，分别停在三个阶段；没有特殊按钮）
- 处理模式：三张选择卡（单选组，选中项朱砂描边 + 角标）；落笔区：空态是邀请，有书时衬线书名 + 格式体积，支持拖入
- 云端缓存卡：左缘「书脊」、圆形对勾、元数据药丸、主操作在标题行、不完整时底部整条警告、费用为 0 时没有游离的 `0`；下方操作行「获取章节 / 配置」在左、「清除缓存」在右
- 书卡悬浮卡：书页感（书名 + 朱砂题签线、软色分类标签、完整简介、格式标签、阅读进度条），内容超过可用高度时卡内纵向滚动，底边渐隐提示「还有」

```bash
pnpm exec vite build --config tests/tour/uiDemo/vite.config.ts
node tests/tour/richDemo/serve.mjs tmp/ui-demo-dist 5199
```

打开 `http://localhost:5199/`，查询参数：`theme=dark`、`cost=1`（有费用）、`partial=1`（缓存不完整）、`file=1`（已选书）、`only=tooltip`（只渲染悬浮卡，直接出现在视口里）。
悬浮卡的滚动要把视口压矮（如 900×300）后再触发一次 `resize`，Radix 才会按可用高度重新算 `max-height`。按端口停服务，不要按进程名杀。
