# reader-workspace Delta

## ADDED Requirements

### Requirement: 全高三栏阅读工作台
总结模式的结果页 MUST 呈现为全高三栏：目录、正文、对照栏；三栏各自独立滚动，页面本身不滚动。

#### Scenario: 读正文时同时看到图表
- **WHEN** 用户在桌面宽度（≥1024px）打开已含关键图表的书并展开对照栏
- **THEN** 正文与图谱同时可见，滚动正文不会使对照栏滚动

#### Scenario: 移动端使用底部抽屉
- **WHEN** 视口宽度 <768px
- **THEN** 对照栏以底部抽屉呈现，提供半屏与全屏两档，目录以左侧 Sheet 呈现

### Requirement: 可拖拽、可收起、可记忆的对照栏
对照栏宽度 MUST 可通过指针拖拽与键盘方向键调整，范围 280–760px；收起状态与宽度 MUST 在本浏览器中被记忆。

#### Scenario: 键盘调整宽度
- **WHEN** 分隔条获得焦点并按下方向键
- **THEN** 宽度按步长变化且不越出范围，`aria-valuenow` 同步更新

#### Scenario: 刷新后保持
- **WHEN** 用户调整宽度并收起对照栏后刷新页面
- **THEN** 宽度与收起状态保持不变

### Requirement: 对照栏页签
对照栏 MUST 提供图谱、时间线、人物志、综述、问书、自测、笔记、原文页签；图谱页签在切走后 MUST 保持挂载以避免重新布局。

#### Scenario: 从章节卡打开原文
- **WHEN** 用户点击章节卡的"原文"
- **THEN** 对照栏展开并切到原文页签，显示该章原文

### Requirement: 阅读进度栏可折叠、可拖拽调宽
左侧目录（含阅读进度）MUST 可折叠为一条极窄的纵向进度条（圆点模式）：轨道上每章一个点，读过的点亮、当前章放大高亮、已读部分的轨道填充，悬停某个点显示章节标题；折叠态 MUST NOT 显示文字或图标按钮。目录宽度 MUST 可拖拽调整（160–360px，双击恢复默认，键盘方向键微调）；折叠态与宽度 MUST 记忆；折叠时目录 MUST 保持挂载（仅隐藏），章节数过多（>40）时 MUST 只画进度线、不画圆点。

#### Scenario: 折叠为进度条
- **WHEN** 用户点击目录的折叠按钮
- **THEN** 目录变为约 14px 的窄条，只显示纵向圆点进度条（无文字），正文区域相应变宽

#### Scenario: 从进度条展开
- **WHEN** 用户点击折叠后的进度条
- **THEN** 目录以折叠前的宽度恢复

#### Scenario: 拖拽调宽
- **WHEN** 用户拖动目录右缘的分隔条
- **THEN** 目录宽度在 160–360px 内变化，并在刷新后保持

### Requirement: 专注模式
系统 MUST 提供专注模式（快捷键 `\`），收起目录与对照栏，仅保留正文。

#### Scenario: 切换专注模式
- **WHEN** 用户按下 `\`
- **THEN** 两侧栏收起；再次按下恢复到之前的宽度与页签

### Requirement: 单行顶栏
全局顶栏 MUST 为单行，包含品牌、书库/阅读分段导航、处理进度胶囊与模型、同步、语言、主题入口。

#### Scenario: 没有结果时阅读入口禁用
- **WHEN** 当前没有可阅读的结果
- **THEN** "阅读"入口禁用并提示原因
