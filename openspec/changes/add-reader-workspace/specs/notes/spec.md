# notes Delta

## ADDED Requirements

### Requirement: 划线与批注
用户选中正文后 MUST 可划线（4 色）、添加批注；笔记锚点 MUST 由章节 id、文本片段与前后文组成，内容变化后 MUST 做模糊重定位，重定位失败时 MUST 保留笔记并标注"已失去定位"。

正文高亮的定位结果 MUST 与笔记页签的"能否定位"判断一致（同一套折叠与三级匹配；两侧 MUST 共用同一份「不可定位块」判定——围栏代码块与缩进代码块、围栏外的原始 HTML 与注释、图片、定义都不参与定位，且该判定 MUST 建立在与正文渲染同一条 markdown 解析链上；引文完全落在不可定位块里时页签同样标「已失去定位」）；一条笔记在正文里 MUST 最多画出一处语义区间（跨块时取起点所在块，不因跨列表项而重复），跨行内格式时 MUST 逐段切开以保持原有格式，引文确实覆盖行内代码时 MUST 标在代码上，围栏代码块 MUST 不参与高亮。整章定位 MUST 是近线性的：一条找不到的引文不得触发全篇逐字扫描。

#### Scenario: 总结重新生成后
- **WHEN** 章节总结被重新生成，原片段仍存在于新文本
- **THEN** 笔记重定位到新位置

#### Scenario: 原片段消失
- **WHEN** 原片段在新文本中找不到
- **THEN** 笔记保留并显示"已失去定位"，不被删除

#### Scenario: 短引文有多处相似候选
- **WHEN** 引文只有几个字，正文别处存在字面相近但并非原文的内容
- **THEN** 高亮画在锚点真正命中的那一处，不画到相似候选上

#### Scenario: 引文跨段落或跨行内代码
- **WHEN** 选区跨了两段，或跨过一段行内代码
- **THEN** 正文里至少画出起点所在的片段（不出现"页签说已定位、正文一处都没有"）

#### Scenario: 长章里的一条过时笔记
- **WHEN** 两万字以上的章节里存在引文已失效的笔记
- **THEN** 定位在毫秒级返回"找不到"，不冻结界面

### Requirement: 笔记存储与同步
笔记 MUST 先写 IndexedDB，再以 3 秒防抖同步到云端：`{syncPath}/.juhua/books/<bookFolder>/notes.json.gz` 信封是跨设备的权威副本，`{name}-笔记.json` MUST 继续作为人可读副本写出（只含可见笔记）。跨设备合并 MUST 以条目为单位（同 `id` 取 `updatedAt` 较大者、相等保留本机），删除 MUST 写墓碑并保留 30 天后丢弃；墓碑 MUST 不出现在界面、Markdown 导出与可读副本中。写入失败 MUST 留在待写队列（下次改动或换书时补推）；云端读取失败、信封读不懂、信封或笔记载荷的版本比本机新时，MUST 一封都不写（含人可读副本），本机内容照常可用。删除书或清缓存时 MUST 询问是否一并删除笔记。

#### Scenario: 离线编辑
- **WHEN** WebDAV 不可用时用户添加笔记
- **THEN** 笔记保存在本地并在恢复后同步

#### Scenario: 两台设备各改了一部分
- **WHEN** 两台设备修改了同一条笔记，一端的时间戳更新
- **THEN** 合并后采用较新的那一份，不产生重复条目

#### Scenario: 一端删除笔记
- **WHEN** 甲设备删除了某则笔记，乙设备仍保留着它的旧副本
- **THEN** 合并结果是墓碑状态，界面与导出都不再显示它，且不会被旧副本复活

#### Scenario: 云端版本更高
- **WHEN** 信封 `schema` 高于本版本能读的值
- **THEN** 本机不覆盖该信封，笔记照常只写本机

#### Scenario: 一次网络抖动
- **WHEN** 读云端信封失败（不是"云端确实没有存档"），之后用户又改了笔记
- **THEN** 本机照常保存，但一封都不写出去，不会用本机旧副本盖掉云端

### Requirement: 导出
系统 MUST 支持导出笔记为 Markdown，以及导出离线可读的单文件学习包 HTML（含总结、彩色图谱/时间线图片、人物志、笔记、自测题）。学习包 MUST 完全自包含（不引用任何外部资源，图片一律内嵌为 data URI）；图谱与时间线 MUST 由图表数据离线重绘（不依赖运行时的图表组件实例），实体颜色 MUST 在导出时解析成具体色值（包内不引用应用的 CSS 变量）。某一张图导不出来时 MUST 只提示、不阻断整包导出。

#### Scenario: 导出学习包
- **WHEN** 用户导出学习包
- **THEN** 得到一个不依赖网络即可打开的 HTML 文件，其中实体颜色与应用内一致

#### Scenario: 图渲染不出来
- **WHEN** 某张图（mermaid 图块或自绘图谱）导出失败
- **THEN** 提示有几张图没导出，正文、笔记与自测照常出现在学习包里

#### Scenario: 没有图谱数据
- **WHEN** 这本书没有实体关系图或时间线数据
- **THEN** 学习包里不出现空的图谱与时间线，其余内容照常导出
