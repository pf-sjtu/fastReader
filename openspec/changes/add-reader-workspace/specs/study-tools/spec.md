# study-tools Delta

## ADDED Requirements

### Requirement: 学习包与三档阅读深度
系统 MUST 能基于章节总结生成学习包（每章一句话、3 个要点、关键术语），持久化到本地与 `{name}-学习包.json`；正文 MUST 提供「一句话 / 要点 / 全文」三档阅读深度切换。

#### Scenario: 切换到一句话
- **WHEN** 用户选择"一句话"档
- **THEN** 每个章节卡只显示该章一句话概括

#### Scenario: 学习包尚未生成
- **WHEN** 学习包不存在
- **THEN** 深度切换中的前两档置灰并提示生成，显示预估费用（价格已知时）

### Requirement: 自测与闪卡
系统 MUST 能按章或全书生成选择题、简答题与闪卡，答案附出处章节并可跳转；输出 MUST 经 schema 校验，解析失败时 MUST 可重试且不丢失已有内容。

#### Scenario: 答错加入错题本
- **WHEN** 用户答错一道题
- **THEN** 该题被加入笔记页签的错题本，附出处章节链接

### Requirement: 问书
系统 MUST 提供对照栏内的问答：上下文由全书综述与按问题检索出的相关章节总结组成；答案 MUST 流式输出并附章节引用，引用可跳转；会话 MUST 只保存在内存。

#### Scenario: 带选区提问
- **WHEN** 用户在正文选中文字并点击"问书"
- **THEN** 问书页签打开，选区作为问题上下文

### Requirement: AI 调用约束
新增 AI 调用 MUST 复用现有流式代理、输出预算与参数退避；MUST 默认手动触发；价格未知时 MUST NOT 估价。

#### Scenario: 被拒的输出上限
- **WHEN** 模型拒绝请求的输出上限
- **THEN** 按既有退避规则重试，最多 3 次
