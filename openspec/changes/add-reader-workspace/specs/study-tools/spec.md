# study-tools Delta

## ADDED Requirements

### Requirement: 速读包与三档阅读深度
系统 MUST 能基于章节总结生成速读包（每章一句话、3 个要点、关键术语），按书的稳定身份持久化到本机（IndexedDB）并同步到云端信封 `{syncPath}/.juhua/books/<bookFolder>/study.json.gz`（速读、自测与答题记录同一封装）；速读与自测 MUST 各自记住自己那一份的上游指纹；云端信封版本更高、读不懂或这一轮没读成时 MUST 只读不写、绝不覆盖；章节较多时 MUST 分批请求（每批 30 章），某一批失败只丢该批，全部失败才报错。正文 MUST 支持「全文 / 要点 / 一句话」三档阅读深度，且仅替换显示用的章节总结（实体索引、缓存、导出仍用全文）；速读包未覆盖的章节 MUST 保持全文。

#### Scenario: 切换到一句话
- **WHEN** 用户选择"一句话"档
- **THEN** 有速读卡的章节卡只显示该章一句话概括，其余章节保持全文

#### Scenario: 速读包尚未生成
- **WHEN** 速读包不存在
- **THEN** 深度切换中的"要点""一句话"两档置灰并提示先生成；生成按钮旁显示用量预估（价格已知时含费用，未知时只给 token，不估价）

#### Scenario: 总结变化使旧速读包失效
- **WHEN** 章节总结被重新生成（内容/章节集合变化）
- **THEN** 上游指纹随之改变，旧速读包与自测 MUST 各自被标注"按旧总结生成"（只有其中一份过时就只标注那一份），自动生成 SHALL 按当前总结重做一次没跟上的那份，而不是把旧内容当成新的

#### Scenario: 重新出题后答案不再对位
- **WHEN** 云端存档里的自测题与重新生成后本机这一套不是同一套题，且两边都有作答记录
- **THEN** 合并结果 MUST 只保留题目来源那一侧的答案，不得把旧答案按题号贴到新题上

#### Scenario: 换设备打开同一本书
- **WHEN** 用户在新设备打开同一本书，云端有速读包而本机没有
- **THEN** 速读包与答题记录从云端信封恢复，无需重新付费生成

#### Scenario: 云端信封版本更高
- **WHEN** 云端信封的 `schema` 高于本版本能读的值
- **THEN** 界面说明"云端那份来自更新的版本"，本机不覆盖它；事后用户答的题只保存在本机

#### Scenario: 生成期间换书
- **WHEN** 速读包/自测/问书生成未完成时用户切换到另一本书
- **THEN** 旧书的结果 SHALL 被丢弃，不写入新书，也不写入旧书的存档

### Requirement: 自测
系统 MUST 能按全书或当前章生成选择题与简答题，答案附出处章节并可跳转；输出 MUST 经 schema 校验，无效题 MUST 被单独丢弃而不影响其余题目，全部无效时 MUST 报错并允许重试。选择题 MUST 即时判对错并展示解析；简答题 MUST 先展示参考答案再由用户自评。同一题 MUST 只记录第一次作答；重新出题 MUST 清空作答记录。

#### Scenario: 答错进入错题本
- **WHEN** 用户答错一道题
- **THEN** 该题计入"只看错题"筛选，并附出处章节链接

### Requirement: 问书
系统 MUST 提供对照栏内的问答：上下文由全书综述与按问题检索出的相关章节总结（CJK 二元组 + TF·IDF，取前 4 章）组成；回答 MUST 只依据这些材料，依据不足时 MUST 明确说明；回答中的「【章节标题】」引用 MUST 映射为可跳转的章节，映射不上的引用 MUST 丢弃。对话 MUST 只存内存（换书即清空），并携带最近 3 轮成功的问答作为指代消解的历史。

#### Scenario: 引用跳转
- **WHEN** 回答包含「【第 2 章】」
- **THEN** 回答下方出现该章节的可点击出处，点击后正文跳到该章

#### Scenario: 取消提问
- **WHEN** 用户在回答生成中点击取消
- **THEN** 请求被中止，该轮标记为已取消，且不影响后续提问

> 当前限制（待办）：回答为**非流式**（provider 层尚无流式接口）；"选中正文后问书"尚未实现；错题目前集中在自测页签的"只看错题"，尚未并入笔记页签。

### Requirement: AI 调用约束
新增 AI 调用 MUST 复用现有 AIService（输出预算、参数退避）；速读 / 自测的**自动补齐**默认开启、界面可关闭，且 MUST 只补「没有」或「按旧总结生成且无答题记录」的产物（已有答题记录的过时自测不自动重做，避免不可恢复地清掉记录）；手动触发与取消始终可用；问书与其余 AI 调用 MUST 手动触发；价格未知时 MUST NOT 估价。

#### Scenario: 被拒的输出上限
- **WHEN** 模型拒绝请求的输出上限
- **THEN** 按既有退避规则重试，最多 3 次
