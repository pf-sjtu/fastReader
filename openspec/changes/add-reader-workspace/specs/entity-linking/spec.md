# entity-linking Delta

## ADDED Requirements

### Requirement: 全局统一实体配色
同一实体 MUST 在图谱、时间线、正文标注、人物志、本章出场条与悬停卡中使用同一颜色；颜色来自 `--entity-1..10` token，light/dark 各一套；超出 10 个的实体 MUST 按类型使用中性色，类型 MUST 另以形状区分。

#### Scenario: 跨视图颜色一致
- **WHEN** 实体"罗斯·约翰逊"同时出现在图谱与时间线
- **THEN** 两处使用相同的 `--entity-N` 颜色

#### Scenario: 深色主题
- **WHEN** 切换到深色主题
- **THEN** 实体颜色切换为深色 token 且与背景对比度满足可读性

### Requirement: 实体—章节索引
系统 MUST 在客户端由章节总结文本与实体名称计算「实体→章节」与「章节→实体」索引，MUST NOT 为此发起 AI 请求；CJK 名称 MUST 至少 2 字才参与匹配；较长名称 MUST 优先于其子串匹配。

#### Scenario: 长名优先
- **WHEN** 实体"罗斯·约翰逊"与"约翰逊"同时存在，文本含"罗斯·约翰逊"
- **THEN** 该片段只匹配前者

#### Scenario: chapterHint 无法匹配
- **WHEN** 事件的 chapterHint 无法映射到任何章节
- **THEN** 该事件的"跳到章节"操作置灰，而不是猜测一个章节

### Requirement: 图表与正文双向联动
当前阅读章变化时，图谱 MUST 高亮本章实体并淡化其余，时间线 MUST 高亮并滚入本章事件；在图谱点击节点或在时间线点击事件 MUST 能跳转到相关章节；节点详情 MUST 显示在对照栏内而不是遮住正文的浮层。

#### Scenario: 滚动正文
- **WHEN** 用户滚动正文使第 7 章成为当前章
- **THEN** 图谱中第 7 章出现的实体高亮，其余淡化

#### Scenario: 点击节点
- **WHEN** 用户点击图谱节点
- **THEN** 对照栏显示该实体简介、关系与出场章节列表，点击列表项跳转到对应章节

### Requirement: 渐进模式
图谱 MUST 提供「截至本章」模式，仅显示读到当前章为止已出场的实体，以避免剧透。

#### Scenario: 开启渐进模式
- **WHEN** 用户开启渐进模式并位于第 3 章
- **THEN** 仅在第 1–3 章出场过的实体可见

### Requirement: 正文实体标注
正文 MUST 可开关地对图表实体加彩色下划线；悬停 MUST 显示简介，点击 MUST 在图谱中定位；标注 MUST 跳过代码与链接。

#### Scenario: 关闭标注
- **WHEN** 用户关闭标注开关
- **THEN** 正文不再渲染 `.entity-mark`，且该偏好被记忆

### Requirement: 图谱可勾选与正文同色
图谱 MUST 提供「与正文同色」开关：开启时节点按统一实体色与形状着色；关闭时使用中性单色样式；偏好 MUST 被记忆；图谱 MUST 显示图例（颜色—实体、形状—类型），并支持按类型过滤。

#### Scenario: 开启同色
- **WHEN** 用户勾选「与正文同色」
- **THEN** 图谱节点颜色与正文标注、时间线列头中同一实体的颜色一致

#### Scenario: 关闭同色
- **WHEN** 用户取消勾选
- **THEN** 图谱回到中性单色样式，正文与时间线的实体色不受影响

#### Scenario: 记忆偏好
- **WHEN** 用户关闭同色后刷新页面
- **THEN** 开关保持关闭

### Requirement: 图谱适应画布
图谱 MUST 在容器从 0 尺寸变为有尺寸时与布局完成时执行一次 fit，使全部节点可见；用户手动缩放或平移后 MUST NOT 自动 fit，并提供"适应画布"按钮。

#### Scenario: 首次显示
- **WHEN** 图谱页签首次变为可见
- **THEN** 所有节点位于画布内
