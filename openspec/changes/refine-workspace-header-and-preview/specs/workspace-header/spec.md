# workspace-header Specification

## Purpose

约束阅读工作台顶栏（`AppHeader compact` + `ResultTitle` + `UnifiedStatusBar variant="meta"`）在宽度收缩时的降级顺序与可读性：控件先退成图标、再折叠进菜单，书名最后才隐藏；任何宽度下书名都不得折成多行。

## ADDED Requirements

### Requirement: 顶栏按优先级降级

工作台顶栏 SHALL 按「模型选择器 → 其它控件 → 折叠进菜单 → 品牌字标 → 书名」的顺序响应宽度收缩，且以顶栏自身可用宽度（容器查询）判断，不以视口宽度判断。

#### Scenario: 模型选择器先退成图标
- **GIVEN** 工作台顶栏渲染了模型切换器
- **WHEN** 顶栏可用宽度低于 992px
- **THEN** 模型切换器只显示图标（`Brain` / `KeyRound`），模型名、思考强度、token 用量与下拉箭头隐藏
- **AND** 按钮的可访问名称仍包含完整模型名（`aria-label`）

#### Scenario: 其它控件再退成图标
- **GIVEN** 顶栏渲染了语言切换与主题切换
- **WHEN** 顶栏可用宽度低于 736px
- **THEN** 语言切换只显示国旗，主题切换只显示日月图标，不再显示文字

#### Scenario: 折叠进菜单
- **GIVEN** 顶栏可用宽度继续收缩
- **WHEN** 顶栏可用宽度低于 512px
- **THEN** 同步状态、退出登录、语言切换、主题切换收进一个「更多操作」菜单
- **AND** 「总结」徽章隐藏
- **AND** 品牌字标（咀华 / JUHUA）隐藏，只保留印章图形

#### Scenario: 书名最后才隐藏
- **GIVEN** 顶栏已折叠到只剩图标与菜单
- **WHEN** 顶栏可用宽度仍低于 288px
- **THEN** 书名整块隐藏；在此之前书名始终可见

### Requirement: 顶栏书名单行显示

工作台顶栏的书名 SHALL 单行显示并以省略号收窄，不得把书名折成多行；作者与章数是次要信息，可早于书名隐藏。

#### Scenario: 窄宽度下书名单行
- **GIVEN** 工作台顶栏可用宽度不足以完整显示「《邓小平时代》解析结果」
- **WHEN** 渲染顶栏
- **THEN** 书名以省略号结尾，顶栏不因书名折行而增高

#### Scenario: 作者与章数先隐藏
- **GIVEN** 顶栏同时显示书名与「作者 | 共 N 章」
- **WHEN** 顶栏可用宽度低于 640px
- **THEN** 作者与章数隐藏，书名保持可见

### Requirement: 折叠不得削弱功能可达性

降级只允许改变呈现形式 SHALL NOT 移除功能：折叠进菜单的每一项都必须可操作。

#### Scenario: 菜单内的控件可用
- **GIVEN** 顶栏处于折叠态（< 512px）
- **WHEN** 用户打开「更多操作」菜单
- **THEN** 菜单提供语言（中文 / English）、主题（浅色 / 深色）、同步状态与退出登录
- **AND** 切换语言或主题后立即生效
